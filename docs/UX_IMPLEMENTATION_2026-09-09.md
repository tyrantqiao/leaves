# Leaves 交互优化实施与验证记录

日期：2026-09-09  
依据：[当前交互界面分析报告](UX_REVIEW_2026-09-09.md)

本轮已将报告中的 12 项问题落实到原型。保留原有 vanilla JS、账号隔离、5 账号上限、铁路手动兜底和航班手动登记方向。

## 已完成的改动

| 报告项 | 实施结果 |
|---|---|
| U01 保存可靠性 | 每个账号独立保存待同步记录；保存失败可见、可重试；刷新不覆盖待同步修改；写入排队，合并其他设备新增记录。服务端采用临时文件替换与版本检查，文件读取失败不再冒充空列表。 |
| U02 表单裁切 | 新增、编辑进入独立对话框；手机使用全高面板，字段区滚动，保存区固定。适配可视视口高度，为软键盘场景保留处理。 |
| U03 错误默认值 | 无路线时不填入北京／上海等城市；起终点必须填写，缺失字段就近报错并获得焦点；沿用历史信息有提示及清空入口。 |
| U04 草稿连续性 | 输入实时保留为账号内草稿；“稍后继续”及 Escape 保留内容；刷新、切页后可恢复；“取消新增／放弃修改”才丢弃。铁路返回填写不丢输入，过时查询结果不再替换当前表单。 |
| U05 行程状态 | 状态与是否填写时间分开；过去日期默认已完成，未来日期默认计划，可手动修改。历史草稿在编辑时提供可确认的新状态，不批量更改既有记录。 |
| U06 筛选一致性 | 空筛选同时清空详情与地图路线；提示“暂无对应方式记录”；显示计数的统计范围。 |
| U07 首屏空间 | 账号、退出、导入、恢复和导出收进“更多”；看板、成就页将快速录入收为登记按钮。手机首页仍同屏保留录入、地图与近期条。 |
| U08 录入步骤 | 航班、铁路、道路与轮船共用一个登记面板；时间、里程、备注按需展开；铁路查询为可选辅助，选择区间后返回同一表单确认保存。机场与车站均有输入联想。 |
| U09 地图表达 | 显示路线示意与里程来源；非当前路线淡化，仅当前路线常驻端点标签；调整定位留白与控件位置，增加“定位当前／查看全部”。 |
| U10 统计口径 | 已完成里程、城市和成就按已完成记录统计；已知同城机场／车站合并，未知地点提示城市待确认；估算里程带“约”；旧记录的未确认来源里程在仅编辑备注时保留。月度图表统一使用里程，标明年月范围。 |
| U11 长期使用 | 新增全部记录、文本／月份／方式筛选；近期条限制 20 条并保留当前选中记录；CSV 和 JSON 先预览影响，提示重复／无效记录；删除与导入前保留可恢复备份。 |
| U12 引导与操作 | 可操作的空状态、字段校验与焦点定位、导航方向键、原生可键盘选择的地点联想、较大的移动端输入与保存控件。成就默认显示已解锁项目与接近完成的目标，支持展开全部。 |

## 验证结果

### 存储与服务端：12 项通过

运行 `npm test`，覆盖：保存失败后刷新与重试、删除后不复活、远端新增合并、写入期间继续编辑、账号切换后的旧请求隔离、异常响应保护、合并规则、版本冲突重试、缓存空间不足提示、请求超时、并发条件写入及损坏文件保护。

### 浏览器：18 项通过

使用 Windows Edge 无头浏览器，在独立临时数据目录中启动本地服务，访问 `http://127.0.0.1:4173`。测试不会使用个人运行数据。

覆盖登录注册门禁、无默认航班路线、必填校验、手动铁路登记、城市合并统计、空筛选、跨页面及刷新恢复草稿、未来计划状态、铁路查询成功／失败／延迟返回、HTTP 500 恢复与重试、历史检索、CSV 文件选择及预览、JSON 无效数据拦截与恢复、旧里程保留、300 条记录、API 并发版本保护和账号隔离。

响应式视口：1440×900、1366×768、1080×740、360×640、390×740、430×740。检查首页无横向溢出、地图和行程条在视口内、表单首字段可操作、滚动可访问后续字段，以及保存按钮始终在视口内。

铁路查询成功和失败均使用可控响应，验证前端流程；不代表真实 12306 当日可用性。第三方地图请求在测试中阻断，验证内置离线底图。

浏览器脚本需要可用的 Playwright 和 Edge；使用已有运行时可在 PowerShell 指定包路径后执行：

```powershell
$env:LEAVES_PLAYWRIGHT_PATH = 'C:\path\to\node_modules\playwright'
npm run test:ui
```

脚本默认启动并关闭专用测试服务，端口为 4173，使用临时数据目录。若端口被占用，可设置 `LEAVES_TEST_PORT` 使用其他端口。输出保存在 `exports/ux-implementation/`，包括截图和 `results.json`。

## 仍需实际环境验证的范围

- 真机软键盘、iOS/Safari、读屏器与系统缩放。本轮完成桌面浏览器视口验证及相应布局处理，未声称完成真机验证。
- 城市归并优先使用机场资料与已有城市／站点映射；无法确定的地点不纳入城市数，并显示待确认数量，不推测全部车站的城市归属。
- 未同步记录和操作前备份存放在当前浏览器、当前账号的缓存内；清空浏览器数据会移除这些本地副本，重要资料仍应导出备份。
- 多设备修改同一条记录时，本地更改优先，并保留写入前的远端快照供恢复；没有实现逐字段的人工冲突比较界面。
- 尚未开展真实用户任务实验，不能据此宣称登记耗时或任务成功率提升了某个百分比。

- `apps/desktop-prototype/app.js`：统一登记、草稿恢复、地图／筛选联动、统计、历史检索和导入预览。
- `apps/desktop-prototype/index.html`、`styles.css`：顶部收拢、独立编辑与数据管理面板、移动端布局。
- `apps/desktop-prototype/trip-store.js`：账号级本地待同步存储与恢复、重试、合并。
- `apps/desktop-prototype/server/trip-storage.js`、`dev-server.js`：原子替换、读取错误保护与条件写入。
- `scripts/test-trip-store.cjs`、`scripts/verify-ux.cjs`：存储及浏览器回归检查。
