# Leaves 产品需求文档

## 1. 产品定位

Leaves 是一个面向个人用户的出行日志工具。用户只需要输入航班号、铁路车次号、起终点或导入票据，就能保存一次行程。之后可以通过地图、时间线、统计报表和年度回顾重新查看这些记录。

核心原则：

- 少填表：默认从一个输入框开始。
- 可回顾：每一次行程都能在时间线和地图上找到。
- 本地可用：没有网络时也能查看和手动登记。
- 数据可信：外部数据源只做补全，用户确认后的记录才进入个人行程库。

## 2. 目标用户

- 经常出差的人：需要记录航班、高铁、打车和费用。
- 旅行爱好者：希望回看去过的城市、路线和年度足迹。
- 铁路/航空爱好者：关心车次、机型、航线、里程和准点率。
- 轻量记账用户：希望把交通费用和票据一起保存。

## 3. MVP 范围

> ✅ 表示已在桌面原型（`apps/desktop-prototype`）中实现并通过验证；其余项待正式 Tauri 版本落地。

### 必须支持

- ✅ 使用单一输入框登记行程。
- ✅ 自动识别基础输入类型：航班号、铁路车次号、地点路线、自由文本。
- ✅ 保存行程的日期、交通方式、编号、起点、终点、时间、备注。
- ✅ 用时间线展示历史行程。
- ✅ 用地图视图展示路线和城市点位（原型使用 Leaflet + OpenStreetMap）。
- ✅ 用本地存储保存数据（原型使用 localStorage，正式版替换为 SQLite）。
- ✅ 支持手动修正自动识别结果（详情栏内联编辑表单）。
- ✅ 支持行程删除与本地 JSON 导入导出。

### 暂不支持

- 实时航班雷达级监控。
- 自动登录 12306、航司、网约车平台。
- 多端云同步。
- 团队协作或企业差旅审批。
- 复杂票务购买功能。

### MVP 验收对照

| 验收项 | 状态 |

| 新增、编辑、删除、查看行程 | ✅ 原型已实现 |

## 4. 核心流程

### 快速登记

1. 用户在顶部输入框输入 `CA1234`、`G1234`、`上海虹桥到杭州东` 等内容。
2. 系统识别交通方式和候选信息。
3. 如果缺少日期或地点，提示用户补充最少字段。
4. 展示预览卡片。
5. 用户确认保存。
6. 行程出现在时间线和地图上。

### 行程回顾

1. 用户进入行程库。
2. 按年份、月份、交通方式筛选。
3. 点击一条行程。
4. 地图聚焦到对应路线，右侧显示详情。

### 年度统计

1. 用户选择年份。
2. 系统汇总里程、次数、城市、运营方、路线和费用。
3. 用户可以导出图片或 HTML 报告。

## 5. 页面结构

- Dashboard：快速登记、近期行程、地图总览、统计摘要。
- Trips：完整行程库，支持搜索、筛选、编辑。
- Map：地图回顾，支持年份、交通方式、城市筛选。
- Stats：里程、次数、费用、城市、运营方、延误统计。
- Settings：数据源、隐私、本地备份、导入导出。

## 6. 成功指标

- 新增一条普通行程不超过 20 秒。
- 用户可以在 3 次点击内回到任意历史行程详情。
- 没有外部数据源时，软件仍然可以完成手动记录。
- 80% 的常见输入能识别出交通方式。
- 原型阶段至少支持 30 条以上本地记录的顺畅浏览。
